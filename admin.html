Payment gateway integration

Enable hosted checkout with any configured provider. Orders are marked paid only after the provider confirms the payment status.

Credential storage. Keys are saved to the server’s private .env file and never returned to this page, so key fields appear blank after a refresh. Leave a key field blank to keep its saved value. For local Stripe testing, use http://127.0.0.1:4173 with Test mode and Stripe test keys. Live mode requires a public HTTPS domain. Stripe webhooks are optional; without one, asynchronous payment, refund, and dispute updates may not sync automatically.

Stripe

Webhook URL: /api/webhooks/stripe
Optional. Recommended for asynchronous payment, refund, and dispute updates; without it, Stripe return verification still confirms completed Checkout payments. Subscribe to checkout.session.completed, checkout.session.async_payment_succeeded, charge.refunded, and charge.dispute.created.

iDEAL via Stripe: Stripe Checkout offers iDEAL alongside cards for Netherlands orders charged in EUR. iDEAL must be available for your Stripe account.

PayPal

Webhook URL: /api/webhooks/paypal
Subscribe to PAYMENT.CAPTURE.COMPLETED, PAYMENT.CAPTURE.REFUNDED, and CUSTOMER.DISPUTE.CREATED.

Authorize.Net

Webhook URL: /api/webhooks/authorize-net
Subscribe to payment authcapture, payment refund, and fraud held/approved/declined events.
